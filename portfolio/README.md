# Lohit P — Portfolio

A dependency-free static portfolio. Open `index.html` directly or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Structure

- `index.html` — content and semantic structure
- `styles.css` — responsive visual system
- `script.js` — minimal reveal behavior
- `assets/` — first-party product assets and résumé

The learning log is intentionally static. Add a new `<li>` inside `.learning-log` whenever you complete or begin a topic.
